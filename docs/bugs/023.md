# Bug 23 — Unfactored code duplication across repositories, services, blueprints, and CLI

**Files:** `neoblogger/app/repositories/articles.py`, `neoblogger/app/services/articles.py`, `neoblogger/app/services/objects.py`, `neoblogger/app/blueprints/blog.py`, `neoblogger/app/blueprints/images.py`, `neoblogger/app/blueprints/seo.py`, `neoblogger/app/wiring.py`, `neoblogger/cli/theme.py`, `neoblogger/cli/users.py`
**Severity:** LOW (duplication / maintainability)

## Description

Eight patterns are duplicated across modules:

1. **ISO 8601 timestamp generation (4 locations, with timezone drift):**
   - `neoblogger/app/services/articles.py:27-29` (`_now_iso()`) — naive local time
   - `neoblogger/app/blueprints/blog.py:215-217` (`_now()`) — naive local time
   - `neoblogger/app/services/objects.py:144` — inline naive local time
   - `neoblogger/cli/theme.py:255-256` (`_now_iso()`) — UTC aware time (`datetime.now(UTC)`)
2. **Proxy-aware fallback base URL (2 locations):**
   - `neoblogger/app/wiring.py:115-126` (`request_base(trust)`)
   - `neoblogger/app/blueprints/seo.py:96-107` (`_request_base(context)`) — byte-for-byte identical `forwarded_base(...)` call.
3. **Markdown → Sanitize → Highlight pipeline (2 locations in `blog.py`):**
   - `neoblogger/app/blueprints/blog.py:74-76` and `79-81` manually chain `highlight_code_blocks(sanitize_html(render_markdown(...)))` instead of calling a single pipeline helper in `neoblogger/app/text/`.
4. **Published/Draft `$facet` count pipeline (2 locations in `ArticleRepository`):**
   - `neoblogger/app/repositories/articles.py:306-331` (`count_by_status`) and `333-359` (`count_by_author`) duplicate the same 20-line `$facet` pipeline and result dictionary construction, differing only by an optional leading `{"$match": {"author": author}}` stage.
5. **Query-string `page` integer parsing (3 locations):**
   - `neoblogger/app/blueprints/blog.py:35-40`, `neoblogger/app/wiring.py:147-151`, and `neoblogger/app/blueprints/images.py:100-105`.
6. **Image caching response headers (2 locations in `images.py`):**
   - `neoblogger/app/blueprints/images.py:126-132` (304 response) and `152-158` (200 response) duplicate `Cache-Control`, `ETag`, and `Last-Modified` header assignment.
7. **CLI account validation & hashing vs `AccountService`:**
   - `neoblogger/cli/users.py:171-215` (`_run_create`), `345-358` (`_run_set_password`), and `373-397` (`_run_set_email`) duplicate input normalization, validation, and Argon2id hashing instead of calling `AccountService`.
8. **Theme banner queries (3 locations):**
   - `neoblogger/app/wiring.py:96-101`, `neoblogger/cli/theme.py:239-245`, and `neoblogger/cli/theme.py:248-252` all hardcode `await context.objects.list_for(THEME_OWNER, 1, 50)`.

## Impact

- Increases maintenance burden and causes subtle behavioral drift (e.g., `cli/theme.py` generating UTC `+00:00` timestamps while `objects.py` generates local naive timestamps, causing `_http_date()` in `images.py:204` to format both with a hardcoded `GMT` suffix).

## Suggested Fix

- Consolidate each duplicated block into a single shared helper in its owning layer (`text/`, `wiring.py`, `articles.py`, `images.py`, `AccountService`, and `services/theme.py`).
