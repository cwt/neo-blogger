# Bug 11 — `Containerfile` ignores `uv.lock` in runtime stage and omits `LICENSE` / `THIRD-PARTY-LICENSES.md`

**Files:** `Containerfile`, `pyproject.toml`
**Severity:** MEDIUM

## Description

1. **Unpinned `pip install` in `Containerfile` (`Containerfile:14-17, 37-40`):**
   `Containerfile:14` copies `uv.lock` into `/build`, but never uses `uv` or lockfile hashes/versions:
   ```dockerfile
   # Containerfile:37-39
   RUN python3.14 -m pip install --no-cache-dir \
           gunicorn "uvicorn[standard]>=0.34" uvicorn-worker \
       && python3.14 -m pip install --no-cache-dir /tmp/wheel/*.whl
   ```
   `pip install /tmp/wheel/*.whl` resolves open-ended version ranges (`argon2-cffi>=23`, `neosqlite>=1.17.2`, `quart>=0.20`, etc.) from PyPI at build time, ignoring `uv.lock`. This violates [Technical Requirements](../technical-requirements.md) §15.2:
   > "Reproducible build (pinned dnf packages + lockfile)."

2. **Missing `THIRD-PARTY-LICENSES.md` and `LICENSE` in runtime container image (`Containerfile:27-58`, `pyproject.toml:12`):**
   [Technical Requirements](../technical-requirements.md) §17.1 mandates:
   > "Vendored assets (Pico CSS, EasyMDE) and any shipped/system ICU libraries require attribution: ship a `THIRD-PARTY-LICENSES`/`NOTICE` bundle in the repo and container image."
   
   In `Containerfile`:
   - `LICENSE` is only copied into the `build` stage (`Containerfile:14`), which is discarded.
   - `THIRD-PARTY-LICENSES.md` is never copied into either stage, nor is it listed in `pyproject.toml:12` (`license-files = ["LICENSE"]`).
   - Consequently, neither the built wheel nor the `runtime` container image contains `THIRD-PARTY-LICENSES.md`.

## Impact

- Container builds are non-reproducible and can pull untested breaking transitive dependency updates from PyPI.
- Distributing the container image or wheel omits the required third-party license attribution bundle (Pico CSS MIT notice, EasyMDE MIT notice, IBM Plex SIL OFL 1.1 notice, ICU notice).

## Suggested Fix

- In `pyproject.toml:12`, set `license-files = ["LICENSE", "THIRD-PARTY-LICENSES.md"]`.
- In `Containerfile`, copy `LICENSE` and `THIRD-PARTY-LICENSES.md` into `/app/` in the `runtime` stage, and install dependencies from locked versions (`uv export --frozen` or `uv sync --frozen --no-dev`).
