# Bug 21 — Dead repository methods in `ArticleRepository` and `MemberRepository`

**Files:** `neoblogger/app/repositories/articles.py`, `neoblogger/app/repositories/members.py`
**Severity:** LOW (dead code)

## Description

Four repository methods are unused by any service, blueprint, or CLI module in `neoblogger/`:

| Method | Location | Status |
|---|---|---|
| `ArticleRepository.covers_in_use_any` | `neoblogger/app/repositories/articles.py:246-255` | Never called anywhere in `neoblogger/` or `tests/` |
| `ArticleRepository.covers_in_use` | `neoblogger/app/repositories/articles.py:237-244` | Superseded by `covers_using_image()` (`articles.py:257`); only called in `tests/test_repo_articles_objects.py:282` |
| `MemberRepository.create` | `neoblogger/app/repositories/members.py:36-71` | Superseded by `create_first_or_member()` (`members.py:73`); only called in `tests/test_repo_members_meta.py` (`create` also lacks the pre-insert `display_name` check that `create_first_or_member` has) |
| `MemberRepository.exists_any` | `neoblogger/app/repositories/members.py:146-150` | Never called in `neoblogger/`; only called in `tests/test_repo_members_meta.py:120` |

## Impact

- No runtime impact; increases maintenance surface and keeps an older non-atomic `MemberRepository.create` path around in tests.

## Suggested Fix

- Remove `covers_in_use_any`, `covers_in_use`, `MemberRepository.create`, and `MemberRepository.exists_any`, and update `tests/test_repo_articles_objects.py` and `tests/test_repo_members_meta.py` to test the active production methods (`covers_using_image` and `create_first_or_member`).

**Status:** Open (see [Bug Tracker](index.md)).
