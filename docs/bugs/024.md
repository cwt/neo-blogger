# Bug 24 — Duplicated test fixtures and helpers across `tests/` (with missing rate-limiter reset)

**Files:** `tests/conftest.py`, `tests/test_web_auth.py`, `tests/test_e2e.py`, `tests/test_web_blog.py`, `tests/test_web_images.py`, `tests/test_cli_maintenance.py`, `tests/test_cli_users.py`, `tests/test_theme.py`
**Severity:** LOW (tests / duplication)

## Description

1. **Shadowed `app` fixture missing rate-limiter reset (`tests/test_web_auth.py:13-20`):**
   `tests/conftest.py:13-25` defines the shared `app` fixture and clears the process-wide rate-limiter buckets (`_signin_limiter`, `_recovery_limiter`, `_signup_limiter`) before each test.
   However, `tests/test_web_auth.py:13-20` redefines its own `app` fixture **without** clearing the rate-limiter buckets:
   ```python
   # tests/test_web_auth.py:13-20
   @pytest.fixture
   async def app(tmp_path: Path) -> AsyncIterator[Any]:
       config = RuntimeConfig()
       config.database.path = str(tmp_path / "web.db")
       application = build_app(config)
       yield application
       await application.extensions["neoblogger_context"].database.close()
   ```
   If tests in `test_web_auth.py` reuse an email address across rate-limit tests, the process-wide `_signin_limiter` / `_signup_limiter` / `_recovery_limiter` state leaks across tests.
2. **Duplicated test helpers across files:**
   - `csrf_token_from`: duplicated in `tests/conftest.py:28-33` and `tests/test_web_auth.py:44-49`.
   - `signup`: duplicated in `tests/test_web_blog.py:16-29` and `tests/test_e2e.py:32-48`.
   - `tiny_webp_bytes` and `storage` / `_storage`: duplicated in `tests/test_e2e.py:14-29` and `tests/test_web_images.py:11-20, 42-49`.
   - `_make_config`: duplicated in `tests/test_cli_maintenance.py:15-26` and `tests/test_cli_users.py:14-25`.
   - `_seed_theme_banner` / `_seed_banner`: duplicated in `tests/test_cli_maintenance.py:285-303` and `tests/test_theme.py:35-49`.

## Impact

- Potential test-order flakiness in `test_web_auth.py` from unreset rate limiters, and duplicated test boilerplate across 8 test modules.

## Suggested Fix

- Remove the duplicate `app` fixture and `csrf_token_from` from `tests/test_web_auth.py` so it uses `tests/conftest.py`, and move shared test helpers (`signup`, `tiny_webp_bytes`, `storage`, `make_config`) into `tests/conftest.py`.
